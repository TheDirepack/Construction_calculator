# Construction Calculator review backlog

Both reviews built commit `1dea3f4` and reported **789 passing tests each**, including three real-plan snapping tests after the fixtures were made available. Sonnet also installed the APK on Android 16 and opened all 13 tools and Settings. It verified a valid PDF import, markup, undo and redo, and export, plus a Foot-Inch result saved to Projects and reopened after relaunch. Whole-document PDF export preserved the source text, page sizes, and rotation in the tested file.

**First fix:** Make project restore durable before reporting success. Next, address the reproduced drawing import and export failure and the misleading calculator outputs. P1 marks the potential loss of project data. P2 marks incorrect results, missing content, or workflows that fail. P3 marks usability friction. Source-verified bugs still need runtime reproduction where indicated.

## Future to-do

- **Portable PDF comments.** Evaluate native editable PDF annotations, filtering, and photo handling in Foxit and another viewer. Keep flattened export available. Treat PDF page organization and direct text or object editing as separate product decisions. Desktop Search and Replace was benchmarked separately. [Foxit Mobile comments](https://help.foxit.com/manuals/pdf-editor/mobile/en_us/2026.4.0/Comment.html) · [Foxit Mobile editing](https://help.foxit.com/manuals/pdf-editor/mobile/en_us/2026.4.0/Edit_PDF_Files.html)
- **Scanned plan support and revision workflows.** Carry forward the roadmap’s offline OCR for scanned plan text and title blocks, plus bulk revision assignment and exportable revision comparisons. Preserve the existing calibrated takeoff and route-to-run workflow. [Roadmap](ROADMAP.md#future-additions--polish-drawings--platform)
- **Published equipment data.** Evaluate manufacturer cable data for pull and fill, drive-specific input current and derating for VFD selection, and equipment-specific bending profiles or fabrication exports. Track source versions and what each dataset covers. [Southwire Cable Pull](https://www.southwire-cablepull.com/) · [Schneider ATV320 manual](https://download.se.com/files?p_Doc_Ref=NVE41289&p_File_Name=ATV320_Installation_manual_EN_NVE41289_09.pdf&p_enDocType=User+guide) · [Greenlee BendWorks](https://www.greenlee.com/us/en/bend-works)
- **Electrical reference editions.** Plan support for NEC 2026 alongside the existing 2023 basis. Keep the selected edition visible in results and reference links. Assess jurisdiction-specific amendments before including them. [NFPA 70](https://www.nfpa.org/en/Codes-and-Standards/Document-information-pages/70)
- **Shared project and revision sync.** Evaluate optional sync, access controls, and revision history as a separate product decision. The current roadmap defines sharing around local projects and file handoff. [Roadmap](ROADMAP.md) · [Procore Android drawing sync](https://support.procore.com/procore-mobile-android/user-guide/drawings-android/tutorials/sync-and-download-drawings-android)
- **Extend Android and data recovery testing.** Cover backup and ZIP migration on a second device, failed writes, process death, system Open/Share, and picker providers. Exercise the drawing workflow from calibration through takeoff and revisions, plus rendered panel exports, accessibility, rotation, and physical stylus input. Add encrypted, very large, and rotated PDFs to the export matrix. Make the real-plan test fixtures available through a repeatable setup.
- **Run matched benchmark cases.** Compare numerical results and input assumptions for Conduit Fill, Voltage Drop, Wire Pull, Reel Length, VFD, Electrical Formulas, and Unit Conversions. Use Greenlee cases to check bending marks and NIST factors to extend conversion coverage. Both reviews used published benchmark material. Side-by-side runs remain pending. [Greenlee manual](https://cdn.greenlee.com/resources/media?key=05cecd71-77e5-448f-ad54-7173d5a28378&languagecode=en&type=document) · [NIST conversion factors](https://www.nist.gov/pml/special-publication-811/nist-guide-si-appendix-b-conversion-factors)
