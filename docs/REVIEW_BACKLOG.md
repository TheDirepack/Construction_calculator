# Construction Calculator review backlog

Both reviews built commit `1dea3f4` and reported **789 passing tests each**, including three real-plan snapping tests after the fixtures were made available. Sonnet also installed the APK on Android 16 and opened all 13 tools and Settings. It verified a valid PDF import, markup, undo and redo, and export, plus a Foot-Inch result saved to Projects and reopened after relaunch. Whole-document PDF export preserved the source text, page sizes, and rotation in the tested file.

**First fix:** Make project restore durable before reporting success. Next, address the reproduced drawing import and export failure and the misleading calculator outputs. P1 marks the potential loss of project data. P2 marks incorrect results, missing content, or workflows that fail. P3 marks usability friction. Source-verified bugs still need runtime reproduction where indicated.

## Improvements

1. **IMP-01 · Preserve text and vectors in sheet and crop exports.** Prioritize a one-page export that retains searchable source text and crisp linework. Verify crop coordinates and markup placement on rotated pages. Keep a clearly labeled raster option for visual snapshots. [PDF editor research](research/pdf-editor-workflows.md)
2. **IMP-02 · Reduce keystrokes for mixed feet and inches.** Prototype quicker entry for common sequences and evaluate a stair-stringer helper. Use Winograd’s Feet & Inch Construction Calc (ArchCalc), the repo’s named reference. Neither review identified a separate Footage Calculator product. Preserve the existing dimensional arithmetic, tape, and project save flow. [Repo reference](research/archcalc.md) · [Winograd Android listing](https://play.google.com/store/apps/details?id=evanwinograd.archcalc)
3. **IMP-03 · Offer ampacity-aware voltage-drop sizing.** Keep the drop-only result available and show which constraint governs when the user supplies the inputs required for an ampacity check. [Southwire Voltage Drop](https://www.southwire.com/calculator-vdrop)
4. **IMP-04 · Add a dedicated Wire Pull Planner PDF report.** Carry over the existing text summary and both pull directions. Include segment results, tension and pressure limits, jam findings, and run details. [Pull Planner notes](tools/pull-planner.md) · [Southwire Cable Pull](https://www.southwire-cablepull.com/)
5. **IMP-05 · Add reel and cable presets with favorites.** Reuse the existing named cable definitions in Reel Length and the linked pull and fill workflows. Preserve custom dimensions and the comparison against footage needed on a run. [Southwire Partial Reel](https://play.google.com/store/apps/details?id=com.southwire.partialReelCalculator)
6. **IMP-06 · Support reusable panel schedule templates.** Build on the existing circuit-linked schedules and PDF, PNG, CSV, and text exports. Use Revit’s desktop templates to benchmark common schedule layouts. [Revit panel schedules](https://help.autodesk.com/cloudhelp/2026/ENU/Revit-DocumentPresent/files/GUID-3D2D0E77-ED17-4FBF-AAE4-CB9185A3F779.htm)
